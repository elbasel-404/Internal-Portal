# User Guide

This comprehensive user guide helps employees navigate and utilize the Portal's features effectively.

## 🏠 Getting Started

### First Login

1. **Access the Portal**
   - Open your web browser
   - Navigate to the Portal URL provided by your IT department
   - Use your company credentials to log in

2. **Dashboard Overview**
   After logging in, you'll see your personalized dashboard with:
   - **Quick Actions** - Frequently used features
   - **Recent Requests** - Your latest submissions
   - **Announcements** - Company news and updates
   - **Calendar** - Upcoming events and deadlines

3. **Navigation**
   - **Top Navigation Bar** - Main menu and user profile
   - **Sidebar** - Quick access to all portal features
   - **Breadcrumbs** - Track your current location

## 👤 Profile Management

### Viewing Your Profile

1. Click on your profile picture/name in the top navigation
2. Select "My Profile" from the dropdown menu

**Profile Information Includes:**
- Personal details (name, contact information)
- Employment information (department, position, start date)
- Emergency contacts
- Bank account details
- Family information

### Updating Your Information

1. Navigate to your profile page
2. Click "Edit Profile" button
3. Update the necessary fields
4. Click "Save Changes"

> **Note**: Some fields may require HR approval for changes.

## 📝 Request Management System

The Portal's request system handles various employee requests efficiently.

### Creating a New Request

1. **Navigate to Requests**
   - Click "Requests" in the sidebar
   - Or use the "New Request" quick action on the dashboard

2. **Select Request Type**
   Choose from available request types:
   - Vacation requests
   - HR letters
   - Medical insurance claims
   - Equipment custody
   - Training requests
   - Bank account changes
   - Remote work requests
   - And more...

3. **Fill Out the Form**
   - Complete all required fields (marked with *)
   - Attach necessary documents
   - Review your information
   - Click "Submit Request"

### Request Types Guide

#### 🏖️ Vacation Requests

**When to Use**: Request time off for vacations, personal days, or sick leave.

**Required Information**:
- Start and end dates
- Vacation type (annual, sick, personal)
- Reason for leave
- Contact information during absence

**Documents Needed**:
- Medical certificate (for sick leave)
- Travel itinerary (for extended vacations)

**Approval Process**:
1. Direct supervisor review
2. HR approval (for extended leave)
3. Final confirmation

#### 📄 HR Letters

**When to Use**: Request official letters for various purposes.

**Available Letter Types**:
- Employment verification
- Salary certificate
- No objection letter
- Experience certificate
- To whom it may concern

**Required Information**:
- Letter purpose
- Recipient details
- Language preference (Arabic/English)
- Delivery method

#### 🏥 Medical Insurance Claims

**When to Use**: Submit claims for medical expenses covered by company insurance.

**Required Information**:
- Patient details
- Medical provider information
- Treatment details
- Claim amount

**Documents Needed**:
- Medical receipts
- Doctor's reports
- Insurance card copy
- Prescription (if applicable)

#### 💻 Equipment Custody

**When to Use**: Request company equipment for work purposes.

**Available Equipment**:
- Laptops and computers
- Mobile phones
- Office furniture
- Specialized tools

**Required Information**:
- Equipment type and specifications
- Purpose and duration
- Return date
- Responsibility acknowledgment

#### 🎓 Training Requests

**When to Use**: Request enrollment in training programs or courses.

**Types of Training**:
- Professional development
- Technical skills
- Leadership programs
- External courses and certifications

**Required Information**:
- Course details
- Training provider
- Duration and schedule
- Budget estimation
- Business justification

### Tracking Your Requests

1. **Request Dashboard**
   - Go to "My Requests" in the sidebar
   - View all your submitted requests
   - Check current status and progress

2. **Status Indicators**
   - 🟡 **Pending** - Awaiting review
   - 🔵 **In Progress** - Being processed
   - 🟢 **Approved** - Request accepted
   - 🔴 **Rejected** - Request declined
   - ⚪ **Completed** - Process finished

3. **Request Details**
   - Click on any request to view full details
   - See approval workflow progress
   - View comments and feedback
   - Download related documents

### Troubleshooting Common Issues

**Login Problems**:
- Check username and password
- Clear browser cache
- Try incognito/private mode
- Contact IT if issues persist

**Form Submission Issues**:
- Check required fields
- Verify file formats and sizes
- Ensure stable internet connection
- Save draft and try again

**Performance Issues**:
- Close unnecessary browser tabs
- Clear browser cache
- Check internet connection
- Try different browser

### Best Practices

**Efficiency Tips**:
